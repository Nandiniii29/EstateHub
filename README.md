# EstateHub

EstateHub is a React-based real estate web application developed as a college project. It provides a modern and responsive platform for exploring property listings, searching and filtering properties, viewing detailed property information, and calculating home loan EMIs.

## Features

- Property search and filtering
- Property listings with detailed information
- Property details and amenities
- User Sign In and Sign Up
- EMI Calculator
- Favourite properties
- Admin dashboard
- Responsive and modern user interface
- Property images from Pexels
- Navigation using React Router

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- React Router
- Pexels Images
