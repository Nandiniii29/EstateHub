# EstateHub
EstateHub is a React-based real estate website developed as a college project for exploring and managing property listings. It provides property search and filtering, detailed property information, user authentication, an EMI calculator, and responsive UI for a smooth property browsing experience.

## Features

- Property search and filtering
- Property listings with detailed information
- Property details and amenities
- User Sign In and Sign Up
- EMI Calculator
- Favourite properties
- Admin dashboard
- Responsive and modern user interface
- Property images from Pexels
- Navigation using React Router

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite
- React Router
- Pexels Images
